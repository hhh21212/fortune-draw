# 三清观求签 🔖

> 纯静态 HTML「抽签」网页，即开即用，可部署到 Netlify / GitHub Pages。

无依赖、无后端的求签页：`index.html` 为完整抽签页，`lookup.html` 为签文查询页。

## ✨ 功能

- 抽签动画 + 签文展示
- 签文查询（`lookup.html`）
- 移动端友好，可「添加到主屏幕」全屏使用

## 🚀 部署

- **Netlify Drop**：把整个文件夹拖到 https://app.netlify.com/drop 即得网址
- **GitHub Pages**：仓库 Settings → Pages → 选 main 分支根目录

> 抽签结果仅供娱乐。
