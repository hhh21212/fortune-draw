三弘道长求签 · 发布到网上（手机用网址打开）
==========================================

你的网页就是一个文件：index.html（已全部打包好，不依赖其它任何文件）。
手机打不开本地文件，所以把它传到网上、拿到一个网址即可。

★ 最简单：Netlify Drop（免费，不用注册就能立刻拿到网址）
1. 电脑浏览器打开  https://app.netlify.com/drop
2. 把「三清观求签」这个文件夹（里面有 index.html）直接拖进网页中央
3. 等几秒，页面会给你一个网址，形如  https://xxxxx.netlify.app
4. 把这个网址发到手机（微信发给自己 / 收藏），手机点开就是求签页
5. 想长期保留：在该页面注册 / 登录 Netlify 免费账号「领取」这个站点，网址即永久有效

★ 永久免费（更正式，稍多几步）：GitHub Pages
1. 注册 GitHub 账号  https://github.com
2. 新建仓库（Repository），名字随意，例如 qian
3. 点「uploading an existing file」，把 index.html 上传进去
4. 仓库 → Settings → Pages → Source 选 main 分支、根目录 → Save
5. 等约 1 分钟，得到网址  https://你的用户名.github.io/qian/
6. 手机打开这个网址即可

★ 手机端建议
- 打开网址后，可用浏览器「添加到主屏幕」，以后点图标即全屏进入（可选）
- 抽签结果仅供娱乐，请勿迷信
